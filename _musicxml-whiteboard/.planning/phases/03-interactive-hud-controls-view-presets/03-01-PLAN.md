    1. Implement camera tween variables and functions in js/view3d.js:
       - Declare global variables:
         ```javascript
         let isTweening = false;
         let tweenStartTime = 0;
         const tweenDuration = 400; // ms
         let startCamPos = new THREE.Vector3();
         let targetCamPos = new THREE.Vector3();
         let startControlsTarget = new THREE.Vector3();
         let targetControlsTarget = new THREE.Vector3();
         ```
       - Implement startCameraTween(destPos, destTarget) which captures current camera.position, controls.target, sets destPos/destTarget, sets isTweening = true, and records tweenStartTime = performance.now().
       - Modify animate() to perform camera linear/cosine interpolation during tween state:
         ```javascript
         if (isTweening) {
             const elapsed = performance.now() - tweenStartTime;
             const t = Math.min(elapsed / tweenDuration, 1.0);
             // Cosine easing for premium feel
             const ease = 0.5 * (1 - Math.cos(t * Math.PI));
             
             camera.position.lerpVectors(startCamPos, targetCamPos, ease);
             controls.target.lerpVectors(startControlsTarget, targetControlsTarget, ease);
             
             if (t >= 1.0) {
                 isTweening = false;
             }
         }
         ```
    2. Bind camera preset button click event listeners:
       - Get width and centerY metrics from createTrackPlanes.
       - **Vista Top**: Target Pos = `(0.1, width * 0.9, 0)`, Target LookAt = `(0, centerY, 0)`.
       - **Vista Lato (Front Profile)**: Target Pos = `(0, centerY, width * 0.9)`, Target LookAt = `(0, centerY, 0)`.
       - **Vista Iso (Default)**: Target Pos = `(width * 0.4, centerY + verticalGap * 1.5 + stackHeight, width * 0.7)`, Target LookAt = `(0, centerY, 0)`.
    3. Bind slider input real-time listeners:
       - **opacity-slider**: Bind to 'input' event. Loops through scene children (meshes representing track planes) and sets material.opacity to the slider value.
       - **spacing-slider**: Bind to 'input' event. Updates `verticalGap` global value. Re-calculates Y position for each track mesh: `mesh.position.y = -index * verticalGap`. Adjusts the current/target controls Y value: `controls.target.y = -((tracks.length - 1) * verticalGap) / 2`. Updates the camera preset target values so dynamic updates persist.
    4. Unhide `#hud-panel` in loadParentState and loadDemoState right after starting Three.js scene.
