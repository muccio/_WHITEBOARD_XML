  <name>Task 2: Build WebGL Engine and Stack Render Loop in js/view3d.js</name>
  <files>js/view3d.js</files>
  <read_first>js/view3d.js</read_first>
  <action>
    1. Implement WebGL engine functions in js/view3d.js:
       - init3dScene(): Initializes the scene, perspective camera, renderer, ambient and directional lights, and OrbitControls. Set OrbitControls target to the center of the stack. Set the initial camera position to a tilted isometric offset above, in front, and to the side.
       - createTrackPlanes(tracks):
         - Loop through tracks. For each track, create a THREE.CanvasTexture from its captured/mock canvas.
         - Set minFilter and magFilter to THREE.LinearFilter. Set wrapS/wrapT to THREE.ClampToEdgeWrapping.
         - Create a THREE.PlaneGeometry with dimensions proportional to the track canvas width and height.
         - Create a THREE.MeshBasicMaterial with transparent: true, opacity: 0.7, map: texture, and side: THREE.DoubleSide.
         - Create the plane mesh. Rotate the mesh flat horizontally: planeMesh.rotation.x = -Math.PI / 2.
         - Set the mesh position: X = 0 (timeline aligned), Y = vertical offset based on stack order (e.g., -index * verticalGap), Z = 0.
         - Create an outline border using THREE.LineSegments and THREE.EdgesGeometry around the plane, with a subtle accent color (#6cefda or matching theme).
         - Add plane and borders to the THREE.Scene.
       - animate(): Render loop that requests animation frames, updates OrbitControls (controls.update()), and renders the scene.
       - handleResize(): Resize listener to adjust camera aspect ratio and renderer size when the browser window is resized.
    2. Update the initialization flow in js/view3d.js:
       - After parsing the parent/demo tracks and capturing textures, hide the #status-view panel.
       - Call init3dScene() and createTrackPlanes().
       - Start the animate() loop.
  </action>
