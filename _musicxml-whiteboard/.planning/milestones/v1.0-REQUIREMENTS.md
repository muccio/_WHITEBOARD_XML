# Requirements

**Analysis Date:** 2026-06-10

## v1 Requirements

### Setup & Sync (SYNC)
- [ ] **SYNC-01**: User can launch the 3D view in a separate tab or window by clicking a "3D" button in the editor controls panel.
- [ ] **SYNC-02**: The 3D page imports parent track structures and metadata dynamically at load time via `window.opener.tracks`.

### 3D WebGL Scene (SCENE)
- [x] **SCENE-01**: Render the tracks as parallel horizontal planes stacked vertically in 3D space using Three.js.
- [x] **SCENE-02**: Align the X-axis timelines of all planes precisely to enable vertical correlation of elements.
- [x] **SCENE-03**: Map the exact visual drawings (SVG) and musical notation boxes (HTML) of each track onto the planes using html2canvas canvas textures.

### Interactive View Controls (CTRL)
- [x] **CTRL-01**: User can rotate, pan, and zoom the camera around the stacked tracks using default OrbitControls.
- [x] **CTRL-02**: User can dynamically adjust the transparency of all track layers using a slider control in the HUD overlay.
- [x] **CTRL-03**: User can dynamically adjust the vertical gap spacing between stacked layers using a slider control in the HUD overlay.
- [x] **CTRL-04**: User can click HUD buttons to snap the camera instantly to view angles: Top (2D orthographic-like), Side (alignment check), and Isometric.

### Architecture & Isolation (ISOL)
- [ ] **ISOL-01**: Build the 3D visualizer in separate static files (`view3d.html` and `js/view3d.js`), maintaining a zero-build static setup and minimizing modifications to existing files.

## v2 Requirements (Deferred)
- [ ] **SYNC-03**: Real-time texture update: automatically redraw 3D textures in real-time as the user draws paths or drags measure boxes in the 2D editor.

## Out of Scope
- Direct element editing, drawing, or notation modifications within the 3D window (read-only view).
- Multi-client real-time synchronization or network servers.
- Volumetric 3D note representations or MIDI-driven note mesh generation (flat canvas textures are sufficient).
