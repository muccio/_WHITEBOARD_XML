# Roadmap: MusicXML Whiteboard Pro 3D

## Overview

This roadmap defines the 3-phase journey to build a read-only 3D multi-track visualizer using WebGL (Three.js) and html2canvas. The visualizer stacks composition tracks vertically as semi-transparent planes, aligning them chronologically along the X-axis. It runs in an isolated browser window/tab, copying the live state from the parent editor window.

## Phases

- [x] **Phase 1: GUI Integration & Data Bridge** - Set up editor launch triggers and memory-based data sharing in the child view.
- [x] **Phase 2: WebGL Stack Engine & Texture Generation** - Composites track DOM elements, generates WebGL canvas textures, and stacks track planes in OrbitControls. (completed 2026-06-10)
- [x] **Phase 3: Interactive HUD Controls & View Presets** - Add overlay controllers for track opacity, vertical spacing gap, and camera preset angles. (completed 2026-06-10)

## Phase Details

### Phase 1: GUI Integration & Data Bridge
**Goal**: Establish the GUI launcher and import live track structures dynamically in the child page.
**Depends on**: Nothing
**Requirements**: SYNC-01, SYNC-02, ISOL-01
**Success Criteria**:
  1. A "3D" button is visible in the main editor's controls panel.
  2. Clicking the button opens `view3d.html` in a new tab.
  3. The child window reads and parses the parent tab's `tracks` array via `window.opener` without security exceptions.
**Plans**: 1 plan

Plans:
- [x] 01-01: Add editor launch button and build basic view3d page script to load parent data structure.

### Phase 2: WebGL Stack Engine & Texture Generation
**Goal**: Compose offscreen track snapshots and map them as textures onto parallel stacked planes in OrbitControls.
**Depends on**: Phase 1
**Requirements**: SCENE-01, SCENE-02, SCENE-03, CTRL-01
**Success Criteria**:
  1. Tracks are rendered as stacked parallel planes in a WebGL canvas container.
  2. Tracks are aligned precisely along the X-axis chronologically.
  3. SVG sketches and MusicXML notation are mapped onto the WebGL planes.
  4. Users can pan, rotate, and zoom the camera around the 3D stacked scene.
**Plans**: 2 plans

Plans:
- [x] 02-01: Implement offscreen track DOM composition capture using html2canvas.
- [x] 02-02: Bootstrap Three.js scene, map canvas textures to transparent planes, and attach OrbitControls.

### Phase 3: Interactive HUD Controls & View Presets
**Goal**: Construct the floating control panel HUD with camera angle presets and parameter sliders.
**Depends on**: Phase 2
**Requirements**: CTRL-02, CTRL-03, CTRL-04
**Success Criteria**:
  1. A floating HUD is overlaid on the WebGL canvas.
  2. Dragging the opacity slider adjusts plane texture transparencies in real time.
  3. Dragging the spacing slider adjusts vertical gap spacing between stacked planes in real time.
  4. Preset buttons snap the camera target instantly to Top-down, Side profile, and Isometric view angles.
**Plans**: 1 plan

Plans:
- [x] 03-01: Build HTML control HUD and implement sliders and camera preset transitions.
